# Orbix — Catálogo digital de mobiliario

Tienda/catálogo web de muebles construido con **Next.js, React y TypeScript**.

- Catálogo con páginas de producto, carrito e inicio de sesión.
- Interfaz animada y enfocada en la experiencia de compra.
- Exploración de funciones inteligentes para recomendar productos.

## Ejecutar

```bash
npm install
npm run dev
```
